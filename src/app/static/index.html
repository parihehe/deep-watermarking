ABOUT THE ARCHITECTURE

Vestigia DWT-SVD Watermarking

Vestigia is a transform-domain digital watermarking platform designed for invisible ownership attribution and robust blind verification.

CORE SPECIFICATIONS

  • Transform: 1-level 2D Discrete Wavelet Transform (Haar)
  • Subband: Low-Low (LL) approximation subband
  • Modulation: SVD singular values modified with frozen multiplicative factor α = 0.020
  • Payload: 4-bit registry ID repeated 15× (60/64 bits) with majority-vote consensus
  • Blind Decoder: Windowed 1D CNN trained on DIV2K images — no original image needed

Developed for computer vision security research and production provenance tracking.
